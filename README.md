# Matemática em Ação

Jogo educativo interativo para estudantes do 6º ao 9º ano.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo: `matematica-em-acao`).
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na própria seção **Pages**.

O projeto já está reunido em um único `index.html`, com estilos e scripts incorporados. Não é necessário instalar nada nem configurar servidor.
